# Real Search Clone

Create a realistic interactive Google mobile search page like real Google on iPhone.

Start with empty search bar.

When the user types "how to become an apple reviewer", the search results appear below.

Make one prominent result:

Title: Apple Product Reviewer - $750 Bonus

Link: appl.reviews750.com

Description: Get paid to share your opinion on Apple products you already use. Complete Your Registration.

Make this link clickable. When clicked, show a loading screen that says "Loading..." for a few seconds.

Use the reference image style for realism. Make everything look very real.
